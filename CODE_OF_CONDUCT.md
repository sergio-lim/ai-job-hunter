# Code of Conduct

This project follows a short, public-domain style code of conduct so contributors and recruiters know what to expect.

## Expected

- Be respectful in issues, pull requests, and reviews.
- Assume good intent; criticize ideas, not people.
- Keep examples generic. No harassment, slurs, or personal data.

## Not welcome

- Personal attacks, harassment, or sustained disruption.
- Publishing private information (emails, chat IDs, resumes, tokens).
- Spam, advertising, or off-topic recruitment pitches in the issue tracker.

## Enforcement

Maintainers may hide, edit, or reject comments and contributions that break this policy, and may block repeat offenders.

Report problems to the maintainers through the repository's private contact form or by opening a confidential security advisory. Do not post the report in a public issue if it contains private data.

This is not legal advice and does not create a contractual obligation beyond the MIT license.
